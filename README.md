# Supervised Learning with Regression Algorithms

![Python](https://img.shields.io/badge/python-%233670A0.svg?style=for-the-badge&logo=python&logoColor=ffdd54)
[![Plotly](https://img.shields.io/badge/plotly-%2907A76FF.svg?style=for-the-badge&logo=plotly&logoColor=white)](#)

A final project for the course CMSC 170 that compares the predictions of four (4) different Supervised Machine Learning Algorithms, namely:

- Linear Regression
- Polynomial Regression
- Ridge Regression
- Autoregressive Integrated Moving Average (ARIMA) Regression

---

### Project files

The project files are structured as follows:

```
/frontend
        # to be filled
/lib
    /Regressions.py # contains all regression algorithms
    /utility.py # has all necessary helper functions
main.py # program entry way
```

Installation instructions:
clone the repository and install the requirements

```
git clone https://github.com/Fylows/CMSC-170-Project.git
cd CMSC-170-Project
pip install --upgrade pip
pip3 install -r requirements.txt
```
